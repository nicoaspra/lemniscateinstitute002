# Objective
This activity introduces students to the process of cutting external threads on a previously turned workpiece. Students will first create a thread relief and then set the compound rest to $29\degg$ to perform threading using the compound rest feed. The activity emphasizes proper alignment, precise tool setup, safe operation, and accuracy in producing threads that meet specification.

# Materials and Equipment
The following materials and tools are essential for successfully completing this activity. Ensure they are available, complete, and in proper working condition before starting.
- Workpiece from previous activity
- HSS Threading Tool (Ground to $60\degg$)
- Vernier Caliper
- Thread Pitch Gauge
- $60\degg$ Center Gauge
- Lathe Machine with Threading Dial Indicator
- Safety Goggles
- Chuck Key

# Procedure
## Preparing the Thread Relief
<ol>
	<li>Compute the <strong>theoretical thread depth</strong> and <strong>minor diameter</strong> based on your design. Show your solution in the ``Calculations'' section.</li>
	<li>Mount the workpiece using the same <strong>center-to-center setup</strong> with the lathe dog and centers.</li>
	<li>Using the <strong>crossfeed dial</strong>, turn a <strong>thread relief groove</strong> at the end of the threaded portion (see Figure 5.1).</li>
	<li>Ensure that the relief matches the <strong>calculated thread depth</strong> and results in a <strong>minor diameter</strong> equal to that of the final thread.</li>
</ol>

## Setting Up the Compound Rest
<ol start="5">
	<li>Rotate the <strong>compound rest to $29\degg$</strong> relative to the axis of the workpiece (see Figure 5.2a). Feeding the tool at an angle causes it to cut primarily on one flank of the thread, reducing tool load and resulting in a smoother, more accurate thread profile (see Figure 5.2b).</li>
	<li>Lock the compound rest <strong>securely</strong>.</li>
	<li>Mount the threading tool in the tool post and adjust its height so the <strong>tip is aligned with the center</strong> of the workpiece.</li>
	<li>Use the <strong>center gauge</strong> to verify that the tool is <strong>perpendicular</strong> to the workpiece axis (see Figure 5.3).</li>
</ol>

## Thread Cutting Operation
<ol start="9">
	<li>Verify that the <strong>threading dial indicator</strong> is functioning properly and is easy to read.</li>
	<li>Set the <strong>spindle speed to a low RPM</strong> suitable for threading, typically between 60--100 RPM.</li>
	<li>Feed the threading tool into the workpiece using only the <strong>compound rest</strong>.</li>
	<li>Engage the <strong>half-nut lever</strong> when the threading dial aligns with the correct number for your thread pitch.</li>
	<li>After each pass, <strong>disengage the half-nut</strong>, <strong>retract the tool using the crossfeed</strong>, and <strong>return the carriage</strong> to the starting point.</li>
	<li>Make an initial pass and check the thread using a <strong>thread pitch gauge</strong> to confirm that the pitch is correct (see Figure 5.4).</li>
	<li>Advance the <strong>compound rest slightly</strong> and repeat the cutting process until the <strong>desired thread depth</strong> is reached.</li>
	<li><strong>Deburr and clean the threads</strong> using a fine file or emery cloth to remove sharp edges and improve finish.</li>
</ol>

## Testing the Thread Fit
<ol start="17">
	<li>Check the thread fit using either the <strong>3-wire method</strong> or a <strong>matching nut</strong>.</li>
	<li>If the fit is tight or uneven, take <strong>light passes to clean</strong> or slightly deepen the thread.</li>
	<li>Record your <strong>final thread dimensions</strong> and compare them to your <strong>calculated values</strong> and <strong>design specifications</strong>.</li>
</ol>
